# 12-435 · No entry for goods vehicles above the weight limit

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-435 · five-digit code 12435</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Any goods vehicles with maximum permissible weight exceeding laden mass limit are forbidden to pass through the designated section of the road.</p>
