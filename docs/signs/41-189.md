# 41-189 · With time charge

<p class="sign-kicker"><a href="../categories/41/">Supplementary panel</a> · pictogram code 41-189 · five-digit code 41189</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Indicates a section of road whose use is subject to a time charge. The sign may also be used to indicate a section of motorway which, unlike the preceding section, is subject to a time charge.</p>
