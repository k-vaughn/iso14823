# 11-999 · Other dangers

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-999 · five-digit code 11999</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of some possible danger. This sign is used in case where no other Warning Signs are applicable.</p>
