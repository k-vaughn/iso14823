# 41-195 · Cyclists allowed in the opposite direction

<p class="sign-kicker"><a href="../categories/41/">Supplementary panel</a> · pictogram code 41-195 · five-digit code 41195</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
