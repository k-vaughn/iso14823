# 12-476 · No entry for vehicles carrying dangerous goods for which special sign plating is required

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-476 · five-digit code 12476</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that vehicles carrying dangerous goods for which special sign plating is required are forbidden to pass through the designated section of the road.</p>
