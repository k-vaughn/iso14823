# 12-455 · No entry for vehicles that are not able or allowed to go faster than specified speed, no microcars, bikes, mopeds and disabled drivers’ vehicles

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-455 · five-digit code 12455</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that vehicles that are not able or allowed to go faster than specified speed, no microcars, bikes, mopeds and disabled drivers’ mobility vehicles are forbidden to pass through the designated section of the road.</p>
