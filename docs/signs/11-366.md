# 11-366 · Airfield

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-366 · five-digit code 11366</p>
<p class="sign-chips"><span class="chip chip-deprecated">Deprecated</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of a section of road likely to be flown over at low altitude by aircraft taking off from or landing on an airfield.</p>
