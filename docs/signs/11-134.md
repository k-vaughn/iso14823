# 11-134 · Intersection with a road the users of which must give way T-shaped crossing right

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-134 · five-digit code 11134</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of a priority road at T-shaped intersection where traffic joining from the right must give way.</p>
