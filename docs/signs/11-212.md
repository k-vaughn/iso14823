# 11-212 · Double bend, first to left

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-212 · five-digit code 11212</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of dangerous double or multiple bends which start with a left curve.</p>
| | |
| --- | --- |
| Service category | <a href="../categories/11/">Warning</a> (11) |
| Pictogram category | 212 |
| Group | Danger warning |
| Status | Current (C) |
| Registered | 2017 |
| UN / Vienna Convention | A, 1c |
