# 12-416 · No motor vehicles except solo motorcycles

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-416 · five-digit code 12416</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles except two wheeled motor cycles without a side-car are forbidden to pass through the designated section of the road.</p>
