# 12-429 · No entry for any power-driven vehicle drawing a trailer other than a semi-trailer or a single axle trailer

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-429 · five-digit code 12429</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that power driven vehicles drawing a trailer other than a semi-trailer or a single axle trailer are forbidden to pass through the designated section of the road.</p>
