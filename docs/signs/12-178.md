# 12-178 · Priority road

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-178 · five-digit code 12178</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
