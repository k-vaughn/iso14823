# 12-577 · Parking prohibited

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-577 · five-digit code 12577</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles are forbidden to park in the designated section of the road.</p>
