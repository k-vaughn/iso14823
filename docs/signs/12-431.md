# 12-431 · No ridden or accompanied horses

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-431 · five-digit code 12431</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
