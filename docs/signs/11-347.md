# 11-347 · Dangerous descent

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-347 · five-digit code 11347</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
