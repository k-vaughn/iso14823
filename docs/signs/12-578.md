# 12-578 · Standing and parking prohibited

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-578 · five-digit code 12578</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles are forbidden to park or stop still in the designated section of the road.</p>
