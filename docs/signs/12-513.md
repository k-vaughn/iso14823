# 12-513 · No entry for vehicles having a weight exceeding specified axle weight on one axle

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-513 · five-digit code 12513</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles with more than the specified axle weight are forbidden to pass through the designated section of the road.</p>
