# 12-511 · No entry for vehicles having an overall height exceeding specified height

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-511 · five-digit code 12511</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles with more than the specified height are forbidden to pass through the designated section of the road.</p>

| --- | --- |
| Service category | <a href="../categories/12/">Regulatory</a> (12) |
| Pictogram category | 511 |
| Group | Prohibition or restriction |
| Status | Current (C) |
| Registered | 2017 |
| UN / Vienna Convention | C,6 |
