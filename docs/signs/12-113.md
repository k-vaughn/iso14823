# 12-113 · Stop specified distance ahead

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-113 · five-digit code 12113</p>
<p class="sign-chips"><span class="chip chip-deprecated">Deprecated</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice of a point of the road where progressing without stopping is prohibited at specified distance ahead. A distance to the crossing from the sign is suffixed to this information.</p>
