# 12-579 · Alternate parking (odd days)

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-579 · five-digit code 12579</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles are prohibited to park on the corresponding side during odd days.</p>
