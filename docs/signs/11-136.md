# 11-136 · Intersection with a road the users of which must give way T-shaped crossing of fork type Lower right

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-136 · five-digit code 11136</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of a priority road at reversed T-shaped forked intersection where the joining traffic from the right must give way.</p>
