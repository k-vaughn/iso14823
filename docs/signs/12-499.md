# 12-499 · No entry for vehicles having an over-all width exceeding specified width

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-499 · five-digit code 12499</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles with more than the specified width are forbidden to pass through the designated section of the road.</p>

| Group | Prohibition or restriction |

| Registered | 2017 |
