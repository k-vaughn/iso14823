# 13-657 · Separation of lanes within the same carriageway (with width restriction)

<p class="sign-kicker"><a href="../categories/13/">Informative</a> · pictogram code 13-657 · five-digit code 13657</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
