# 13-651 · Closure of traffic lane(s) and traffic merging

<p class="sign-kicker"><a href="../categories/13/">Informative</a> · pictogram code 13-651 · five-digit code 13651</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice of closure of traffic lane(s) and traffic merging. If it is not specified otherwise it implies the closure of one or more lanes is on the right.</p>
