# 41-198 · Tunnel category

<p class="sign-kicker"><a href="../categories/41/">Supplementary panel</a> · pictogram code 41-198 · five-digit code 41198</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>The sign supplements the main sign &quot;No entry of vehicles carrying dangerous goods&quot; and informs about the relevant tunnel category in the following road section. The indication of the category shall be given in the range of letters &#x27;B&#x27; to &#x27;E&#x27; according to UNECE ADR regulation ).</p>
