# 12-558 · Use of audible warning devices prohibited

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-558 · five-digit code 12558</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that for motor vehicle it is prohibited from blowing the horns for warning when passing through the designated section of the road.</p>
