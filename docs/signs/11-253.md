# 11-253 · Light signals

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-253 · five-digit code 11253</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Give warning of a section of road on which traffic is regulated by three-colour light signals, because road users would not expect such a section.</p>
| | |
| --- | --- |
| Service category | <a href="../categories/11/">Warning</a> (11) |
| Pictogram category | 253 |
| Group | Danger warning |
| Status | Current (C) |
| Registered | 2017 |
| UN / Vienna Convention | A17 |
