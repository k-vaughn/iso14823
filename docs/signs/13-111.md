# 13-111 · Advance direction signs

<p class="sign-kicker"><a href="../categories/13/">Informative</a> · pictogram code 13-111 · five-digit code 13111</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice of direction(s) and destination(s) on the next junction with indications of the junction layout, place name(s) and the distance(s) from there, if any.</p>

| --- | --- |
| Service category | <a href="../categories/13/">Informative</a> (13) |
