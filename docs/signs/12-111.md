# 12-111 · Priority for oncoming traffic

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-111 · five-digit code 12111</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that drivers must give way to oncoming traffic on a narrow section ahead.</p>
