# 41-191 · With toll

<p class="sign-kicker"><a href="../categories/41/">Supplementary panel</a> · pictogram code 41-191 · five-digit code 41191</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Indicates the section of road whose use is subject to tolls. The sign can also be used to indicate a section of motorway whose use is subject to tolls, unlike the previous section.</p>
