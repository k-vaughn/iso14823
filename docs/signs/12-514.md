# 12-514 · No entry for vehicles or combinations of vehicles exceeding specified length

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-514 · five-digit code 12514</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles with more than the specified length are forbidden to pass through the designated section of the road.</p>
