# 11-175 · Left turn

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-175 · five-digit code 11175</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice of a single sharp curve (turn) to the left. A turn is differentiated from a curve by combining all elements of speed, radius of curve, road rate of incline, intersection angle and visible distance.</p>
