# 41-188 · No time charge

<p class="sign-kicker"><a href="../categories/41/">Supplementary panel</a> · pictogram code 41-188 · five-digit code 41188</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Indicates a motorway section that is not subject to a time charge. The sign may also be used to indicate a section of the motorway which, unlike the preceding section, is not subject to a time charge.</p>
