# 41-190 · Without toll

<p class="sign-kicker"><a href="../categories/41/">Supplementary panel</a> · pictogram code 41-190 · five-digit code 41190</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Indicates a section of motorway that is not subject to tolls. The sign can also be used to indicate a section of the road which, unlike the previous section, is not subject to tolls.</p>
