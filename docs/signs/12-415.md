# 12-415 · Closed to all vehicles in both directions

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-415 · five-digit code 12415</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that all vehicles are forbidden to pass through the designated section of the road.</p>
