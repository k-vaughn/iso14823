# 12-515 · Driving of vehicles less than specified distance apart prohibited

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-515 · five-digit code 12515</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that drivers must maintain the specified distance from the preceding vehicle when driving in the designated section of the road.</p>
