# 13-168 · Motorway entrance

<p class="sign-kicker"><a href="../categories/13/">Informative</a> · pictogram code 13-168 · five-digit code 13168</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
