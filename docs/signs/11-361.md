# 11-361 · Cross-wind

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-361 · five-digit code 11361</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of the possibility of sudden side wind that may hinder travelling at normal speeds.</p>
