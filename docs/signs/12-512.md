# 12-512 · No entry for vehicles exceeding specified weight

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-512 · five-digit code 12512</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice that motor vehicles with more than the specified weight are forbidden to pass through the designated section of the road.</p>
| | |
| --- | --- |
| Service category | <a href="../categories/12/">Regulatory</a> (12) |
| Pictogram category | 512 |
| Group | Prohibition or restriction |
| Status | Current (C) |
| Registered | 2017 |
| UN / Vienna Convention | C,7 |
