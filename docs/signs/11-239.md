# 11-239 · School crossing ahead

<p class="sign-kicker"><a href="../categories/11/">Warning</a> · pictogram code 11-239 · five-digit code 11239</p>
<p class="sign-chips"><span class="chip chip-deprecated">Deprecated</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Warning of an area where children may exit from a school or playground frequently pass by and cross the road from the right side.</p>
