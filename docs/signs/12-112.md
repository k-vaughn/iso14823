# 12-112 · STOP

<p class="sign-kicker"><a href="../categories/12/">Regulatory</a> · pictogram code 12-112 · five-digit code 12112</p>
<p class="sign-chips"><span class="chip chip-current">Current</span> <a class="chip chip-draft" href="../#draft-watermark">Draft</a></p>
<p>Notice of a point on the road where progressing without stopping is prohibited.</p>
